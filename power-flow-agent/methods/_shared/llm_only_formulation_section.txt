## Formulation

Add a `formulation` field to the JSON object: an ordered list of {"tool": "<name>", "args": {...}} objects, one per operation the request needs, in execution order, using only the operations and argument names below (* = required). Copy identifiers and values from the request; do not add arguments the request does not give. This field declares your understanding of the request.
