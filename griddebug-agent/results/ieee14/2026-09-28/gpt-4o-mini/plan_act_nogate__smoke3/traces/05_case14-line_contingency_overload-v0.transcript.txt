## Tools

### query tools
- get_network_summary(): Get high-level summary: bus count, line count, generators, loads, convergence status.
- get_bus_data(bus_ids: array): Get bus table (optional: list of bus indices to filter).
- get_line_data(line_ids: array): Get line table with from_bus, to_bus, in_service (optional: line indices).
- get_gen_data(gen_ids: array): Get generator table: bus, p_mw, in_service, max_p_mw (optional: gen indices).
- get_voltage_profile(): Get bus voltage magnitudes (vm_pu) and angles; only available if power flow converged.
- get_loading_profile(): Get line and transformer loading (percent); only available if power flow converged.
- get_power_balance(): Get total load P/Q, total generation P/Q, total active power loss (MW), and load/gen ratio.
- get_line_results(line_ids: array): Get power flow results for lines: p_from_mw, p_to_mw, q_from_mvar, q_to_mvar, pl_mw (losses), loading_percent. Only available if power flow converged.
- get_bus_results(bus_ids: array): Get power flow results for buses: vm_pu, va_degree, p_mw, q_mvar. Only available if power flow converged.

### simulation tools
- run_power_flow(): Run the AC power flow (Newton-Raphson) on the current network. Returns whether it converged. Run it after every change; the results tables are only valid for the network as it was at the last run.
- run_n1_contingency(line_index: integer, trafo_index: integer): What-if: take one line or one transformer out of service on a copy of the network, run the power flow there and report its violations. The current network is not changed. Pass line_index or trafo_index.

### diagnostic tools
- run_full_diagnostics(): Run pandapower network diagnostic (checks topology, indices, etc.). Returns dict of test names to results.
- check_overloads(threshold_percent: number): Check line and transformer loading above a threshold (default 100%). Returns overloaded elements.
- check_voltage_violations(v_min: number, v_max: number): Check bus voltages outside [v_min, v_max] pu (default 0.95–1.05). Returns under/over voltage buses.
- find_disconnected_areas(): Find buses not connected to the external grid (topology check).

### action tools
- adjust_generation(gen_index: integer (required), gen_type: string, p_mw_new: number, vm_pu_new: number): Redispatch: adjust a generator's real power (p_mw) or voltage setpoint (vm_pu). Use to fix power imbalance or voltage issues.
- curtail_load(load_index: integer (required), scale_factor: number (required)): Curtail a single load by a scale factor (0.0–1.0). Use for targeted load shedding at critical buses.
- scale_all_loads(factor: number (required)): Global demand response: scale ALL loads by a factor (0.0–1.0). Use when system-wide generation is insufficient.
- switch_element(element_type: string (required), element_index: integer (required), in_service: boolean (required)): Toggle any element in/out of service. Use for topology switching (lines/trafos) or shedding loads/gens.
- add_shunt_compensation(bus_index: integer (required), q_mvar: number (required)): Add reactive shunt compensation (capacitor/reactor) at a bus for voltage control. Positive q_mvar = capacitive (raises voltage).
- adjust_voltage_setpoint(element_type: string (required), element_index: integer (required), vm_pu_new: number (required)): Set the voltage setpoint (vm_pu) of a generator or external grid. Use for reactive power / voltage control.
