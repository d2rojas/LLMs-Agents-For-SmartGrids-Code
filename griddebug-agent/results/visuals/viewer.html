How to use

Left: every run; filter by model and method. Middle: its scenarios with outcome and diagnosis. Right: the real trace of the scenario as the method left it (trace tab): every model message, every tool call with its output, the gate attempts and the final answer. Nothing is rebuilt: if a run did not store something, it says so. The other tabs show the text transcript, the narrative and the raw JSON.

Compare with shows the same scenario from another run side by side. Notes are kept in this browser; Export annotations downloads them as JSON.
